# Employee Working Hours Tracker - Angular

This is a simple Angular application that displays employee working hours using data from an API.

## Technologies Used
- Angular
- TypeScript
- Chart.js
- HTML and CSS

## Features
- Gets employee data from an API
- Calculates total working hours for each employee
- Skips deleted and invalid entries
- Sorts employees by total hours
- Highlights employees with less than 100 hours
- Displays a pie chart showing each employee's percentage of total working hours

## How to Run
1. Open the project in VS Code.
2. Run `npm install` in the terminal.
3. Run `ng serve`.
4. Open `http://localhost:4200` in your browser.
5. Enter the API key and click **Load Employees**.
